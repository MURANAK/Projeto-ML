# Sobre o Projeto
É um projeto feito por membros do PET Computação da UFRGS para aprender na prática sobre Machine Learning especificamente
para estudar e aplicar o método de Q-learning de forma lúdica para fins demonstrativos.

# O jogo
A ideia do jogo é simples, barris e bananas caem do céu, e o objetivo do jogador é tentar sobreviver o máximo de tempo possível
desviando dos barris e coletando as bananas para ganhar pontos.

# A IA
## Q-Learning
A IA será treinada usando o Q-learning, que é uma forma de aprendizado por reforço. Esse método tem como base recompensas e punições.
Cada ação feita pela IA será recompensada ou punida e ela guarda o quão bom ou ruim é realizar aquela ação no chamado Q-table.
A decisão da IA é feita a partir de uma fórmula que analisa o estado atual da IA, as possíveis ações que ela pode tomar, a possível situação futura que 
a IA estaria se ela fizesse essas ações, o quanto a IA aprecia as recompensas e uma taxa de curiosidade para encorajar o agente a tomar decisões diferentes.
